## 📌 О проекте

**Parser** — это Python-проект, созданный для изучения принципов работы парсеров и автоматизированной обработки данных.

Основная идея проекта — научиться получать информацию из источников, обрабатывать её и работать с данными программным способом.

Проект является частью моего пути изучения Python и backend-разработки.

---

## 🎯 Цель проекта

Главная задача проекта — закрепить практические навыки:

- 🐍 работы с Python;
- 📄 обработки данных;
- 🔍 поиска и извлечения информации;
- ⚙️ автоматизации рутинных задач;
- 🧩 построения логики обработки данных.

## 🚀 Запуск проекта

Клонировать репозиторий:

```bash
git clone https://github.com/Art1kAHAHA/Parser.git
```

Перейти в папку проекта:

```bash
cd Parser
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить:

```bash
python main.py
```
