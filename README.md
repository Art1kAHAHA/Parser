# 🕷️ Web Parser

> Учебный парсер на Python для сбора и обработки данных с веб-страниц.

## 📌 О проекте
Скрипт, написанный на Python, который использует библиотеки `requests` и `BeautifulSoup` для извлечения информации с веб-сайтов.  
Проект демонстрирует базовые навыки работы с HTTP-запросами, обработкой HTML-структуры и сохранением данных.

## 🚀 Запуск локально
1. Клонируйте репозиторий.
2. Установите зависимости:
pip install requests beautifulsoup4
3. Запустите скрипт:
python pars.py

## ⚙️ Функционал
- ✅ Отправка HTTP-запросов к веб-сайтам.
- ✅ Парсинг HTML-кода с использованием BeautifulSoup.
- ✅ Поиск элементов по тегам, классам или ID.
- ✅ Вывод собранных данных в консоль или сохранение в файл.

## 🎯 Цели проекта
- Понять принцип работы клиент-серверного взаимодействия.
- Научиться обрабатывать HTML-структуру.
- Закрепить навыки работы с библиотеками Python для веб-скрапинга.
